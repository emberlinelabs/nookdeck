# Example plugins

| Plugin | What it shows |
|---|---|
| [crypto-price](crypto-price) | Live USD price of a coin (no-code, `http` source, `stat` renderer) |
| [github-stars](github-stars) | Star count and history of a repository (code, `net.fetch`, `storage`, `stat` and `chart`) |
| [uptime-ping](uptime-ping) | Is a web address up, and how fast (code, `status` renderer) |
| [clipboard-snippets](clipboard-snippets) | Buttons that copy saved text (no code, `shell` permission) |
