# GitHub stars

A code plugin. Two tiles for a repository: the current star count, and a chart of the count each time it was read.

- **Access it asks for:** `api.github.com` only, and its own saved data (the chart history). No shell, no keyboard.
- **Settings:** the repository (per tile) and an optional GitHub token (plugin-wide, secret: kept on the computer, never sent to phones).
- **Shows:** `stat` and `chart` renderers.
- **Develop:** `nookdeck plugin dev examples/plugins/github-stars`.
